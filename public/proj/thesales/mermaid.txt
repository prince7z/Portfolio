sequenceDiagram

    participant User
    participant Frontend
    participant API as Express API
    participant Auth as JWT Middleware
    participant Service as AutoPrice Engine
    participant DB as MongoDB
    participant TA as TakeAlot API

    User->>Frontend: Configure AutoPrice Rule

    Frontend->>API: POST /api/autoprice/set-autoprice

    API->>Auth: Verify JWT Token

    Auth->>DB: Load User + Integration

    DB-->>Auth: User Context

    Auth-->>API: Authorized

    API->>Service: Validate Rule

    Service->>DB: Create/Update AutoPay Document

    DB-->>Service: Saved

    Service-->>API: Success Response

    API-->>Frontend: AutoPrice Enabled

    loop Every 15 Minutes
        Service->>TA: Fetch Competitor Prices
        TA-->>Service: Pricing Data

        Service->>Service: Calculate New Price

        Service->>TA: Update Marketplace Price

        TA-->>Service: Update Confirmation

        Service->>DB: Store Audit Log
    end
